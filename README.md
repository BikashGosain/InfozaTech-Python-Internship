## Tasks

### Task 1 — To-Do List Application

A command-line To-Do List application developed using Python.

**Implemented features:**

* Add new tasks
* View pending tasks
* Mark tasks as completed
* Delete tasks
* JSON-based persistent storage
* Task priority levels
* Due dates
* Priority and deadline-based sorting
* Input validation

**Technologies:** Python, JSON, `pathlib`, `datetime`

[View Task 1 →](Task-1-TO-DO%20LIST%20APPLICATION/)

### Task 2 — Rock Paper Scissors Game

A command-line Rock Paper Scissors game where the user plays against the computer across multiple rounds.

**Implemented features:**

* User selection of Rock, Paper, or Scissors
* Computer-generated random choices
* Winner determination
* Running score tracking
* Draw handling
* Multiple rounds
* Final score display
* Input validation

**Technologies:** Python, `random`

[View Task 2 →](Task-2-Rock-Paper-Scissors-Game/)

---

### Task 3 — BMI Calculator

A command-line BMI Calculator that calculates Body Mass Index based on height and weight.

**Implemented features:**

* Height input in centimeters or meters
* Weight input in kilograms
* BMI calculation
* BMI category classification
* Input validation
* BMI history
* JSON-based persistent storage
* Multiple historical readings

**Technologies:** Python, JSON, `pathlib`, `datetime`

[View Task 3 →](Task-3-BMI-Calculator/)

---

### Task 4 — Password Generator

A command-line password generator that creates passwords based on user-selected character sets.

**Implemented features:**

* Custom password length
* Letters selection
* Numbers selection
* Symbols selection
* Secure password generation using `secrets`
* Input validation
* Multiple password generation
* JSON-based persistent storage
* View saved passwords

**Technologies:** Python, `secrets`, `string`, JSON, `pathlib`

[View Task 4 →](Task-4-Password-Generator/)

---

### Task 5 — Contact Book

A command-line Contact Book application for managing contact information using SQLite.

**Implemented features:**

* Add new contacts
* View all contacts
* Search contacts by name
* Update existing contacts
* Delete contacts
* Input validation
* SQLite database persistence
* CRUD operations
* Parameterized SQL queries

**Technologies:** Python, SQLite, `sqlite3`, `pathlib`

[View Task 5 →](Task-5-Contact-Book/)
